# Background Images

This directory contains background images for the rotating background feature.

## Required Images

Add 4 festival/concert background images here:
- `bg1.jpg` - First background image
- `bg2.jpg` - Second background image
- `bg3.jpg` - Third background image
- `bg4.jpg` - Fourth background image

## Recommended Specs

- **Format**: JPG or PNG
- **Dimensions**: 1920x1080 or higher (16:9 aspect ratio)
- **File Size**: Optimized for web (< 500KB each)
- **Content**: Festival scenes, crowd shots, stage photos, venue views

## Tips

- Use high-quality images that represent your festival brand
- Images should work well with a dark overlay (text needs to be readable on top)
- Consider variety - mix of crowd shots, stage views, and venue atmosphere
- Ensure you have rights to use all images
